# Cinemana Reverse Engineering
## CTV Platform Engineering Specification

Version 1.0

---

# Purpose

This document defines how CTV Platform communicates with Cinemana.

It specifies the discovery process, endpoint analysis, request flow,
authentication strategy, stream extraction, subtitle extraction,
and synchronization rules.

This document defines WHAT the system should achieve.

Implementation details may evolve as Cinemana changes.

---

# Important Principle

Cinemana is the ONLY content provider.

No movie shall exist inside the platform unless it exists on Cinemana.

TMDB NEVER creates content.

TMDB only enriches metadata.

---

# Reverse Engineering Philosophy

The system MUST NOT depend on undocumented assumptions.

Every API endpoint must be discovered automatically.

The platform must tolerate endpoint changes.

# Stream Rules

Movie may contain multiple streams.

Streams must never overwrite each other.

---

# Subtitle Rules

Multiple subtitle languages are allowed.

Multiple subtitle formats are allowed.

# Acceptance Criteria

The Cinemana Provider is considered complete when it can

✓ Discover all available movies.

✓ Discover all TV shows.

✓ Extract all streams.

✓ Extract all subtitles.

✓ Detect removed content.

✓ Synchronize changes automatically.

✓ Recover after provider changes with minimal updates.
