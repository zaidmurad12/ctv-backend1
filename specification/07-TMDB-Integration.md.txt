# TMDB Integration
## CTV Platform Engineering Specification

Version 1.0

---

# Purpose

This document defines how CTV Platform integrates with The Movie Database (TMDB).

TMDB is used ONLY as a metadata provider.

TMDB is NEVER considered a content provider.

---

# Primary Rule

TMDB SHALL NEVER create a Movie.

TMDB SHALL NEVER create a TV Show.

TMDB SHALL NEVER create an Episode.

Only Cinemana may introduce new content into the platform.

---

# Responsibilities

TMDB is responsible for enriching existing content with metadata.

It provides

• Overview
• Genres
• Cast
• Crew
• Posters
• Backdrops
• Logos
• Ratings
• Vote Count
• Runtime
• Collections
• Production Companies
• Countries
• Languages
• Trailers
• Release Dates
• Keywords

Streams belong to Cinemana.

# Acceptance Criteria

TMDB integration is considered complete when

✓ Movies are matched correctly.

✓ TV Shows are matched correctly.

✓ Seasons are matched correctly.

✓ Episodes are matched correctly.

✓ Metadata updates automatically.

✓ Images download correctly.

✓ Collections import correctly.

✓ Cast imports correctly.

✓ Crew imports correctly.

✓ Companies import correctly.

✓ No movie is created directly from TMDB.

✓ No stream information is requested from TMDB.

✓ No subtitle information is requested from TMDB.
