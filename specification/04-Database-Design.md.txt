# Database Design
## CTV Platform Engineering Specification

Version 1.0

---

# Purpose

This document defines the complete database architecture for the CTV Platform.

It specifies all entities, relationships, constraints, indexes, and data ownership rules.

This document is the single source of truth for the database schema.

# Constraints

Movie cannot exist without Provider.

Stream must belong to Movie or Episode.

Subtitle must belong to Movie or Episode.

Episode must belong to Season.

Season must belong to TV Show.

---

# Soft Delete

All major entities support

deletedAt

instead of physical deletion.

---

# Cascade Rules

Delete TV Show

↓

Delete Seasons

↓

Delete Episodes

↓

Delete Streams

↓

Delete Subtitles

---

# Database Rules

Provider IDs must remain immutable.

TMDB IDs must never be duplicated.

Movie titles are NOT unique.

UUID is mandatory.

No nullable foreign keys unless documented.

No JSON columns unless explicitly approved.
