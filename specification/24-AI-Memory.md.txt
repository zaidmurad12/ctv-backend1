# Architectural Baseline

The platform is designed around the following decisions:

- Clean Architecture
- Modular Monolith in Phase 1
- Provider-based integration model
- Core independence from external providers
- Cinemana as the only content source
- TMDB as a metadata enrichment provider only
- PostgreSQL and Prisma as the persistence foundation
- Redis and BullMQ for caching and asynchronous workers
- REST API as the main client integration contract
- Android TV and admin dashboard as client applications

# Current Implementation Focus

The project has moved from repository foundation into Milestone 1 Sprint 1: the Core Domain.

The current work focuses on:

- creating a pure domain layer in TypeScript
- implementing domain entities with validation and invariants
- introducing value objects for domain-safe primitives
- defining repository interfaces for the business model
- introducing domain events and domain-specific errors
- keeping the implementation completely free of Prisma, infrastructure, providers, HTTP, and persistence concerns

No infrastructure or application-layer implementation should be introduced at this stage.

## Milestone 1 Sprint 1 + Sprint 2 Update

Status: Completed

Major deliverables completed:
- Added a framework-independent domain package under packages/domain.

- Added domain events and domain errors.

- Verified compilation with TypeScript.

Architectural decisions validated:
- The domain layer remains independent from Prisma, Redis, HTTP, providers, and infrastructure.
- Domain invariants, validation, and lifecycle behavior are centralized in the domain layer.
- Shared abstractions now support richer domain patterns without introducing infrastructure concerns.

Verification completed:

Next recommended actions:
